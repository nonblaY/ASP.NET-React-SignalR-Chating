# Realtime Chat

Онлайн-чат с комнатами в реальном времени. Пользователь вводит никнейм и имя комнаты, после чего попадает в чат и обменивается сообщениями с другими участниками этой комнаты.

## Возможности

- Вход в чат по никнейму и названию комнаты
- Сообщения в реальном времени через WebSocket (SignalR)
- Отдельные комнаты: сообщения видят только участники комнаты
- Системные уведомления о входе и выходе пользователей
- Хранение информации о подключениях в Redis

## Технологии

**Frontend**
- React (Create React App)
- Tailwind CSS v3
- Chakra UI v2

**Backend**
- ASP.NET Core (.NET 8)
- SignalR
- Redis

## Требования

- .NET SDK 8
- Node.js 18 или новее
- Docker

## Запуск

Нужно три процесса: Redis, бэкенд и фронтенд.

### 1. Redis

Проверка: `docker ps` должен показать контейнер `redis` со статусом `Up` и портом `6379`.

> Если на Linux команда пишет `permission denied`, добавьте пользователя в группу docker и перелогиньтесь:
> `sudo usermod -aG docker $USER`

### 2. Backend

```bash
cd backend/MyApi~
dotnet run
```

### 3. Frontend

```bash
cd frontend/chat
npm install
npm start
```

Приложение откроется на `http://localhost:3000`.

## Как это работает

1. Пользователь заполняет форму в `WaitingRoom`, фронтенд создаёт соединение SignalR и вызывает метод хаба `JoinChat`.
2. Сервер добавляет подключение в группу комнаты и сохраняет пару «ID подключения → пользователь и комната» в Redis.
3. При отправке сообщения вызывается `SendMessage`: сервер по ID подключения находит комнату и рассылает сообщение всем участникам группы методом `ReceiveMessage`.
4. При отключении запись удаляется из Redis, а в комнату уходит уведомление «покинул чат».
